# Sonic 美東行 2027

Sonic 2027 年 4 月到美國找 Victoria 的旅行手冊：費城、紐約、華盛頓。

- `index.html`：頁面外框和封面
- `data.js`：全部行程資料（每日行程、航班、交通、要先訂的票、住宿、注意事項），要改內容改這個檔
- `app.js`：把資料排成各個分頁
- `style.css`：樣式（藍天白雲封面、紐約地鐵站牌風格）

純靜態網站，沒有建置步驟。改完 `data.js` 後，把 `index.html` 裡 `?v=` 的日期也改掉，瀏覽器才會抓到新版。

開放時間、票價和訂票規則查於 2026 年 11 月，出發前要再確認。
