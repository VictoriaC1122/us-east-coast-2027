# Sonic 美國東岸旅行手冊 2027

Sonic 2027 年 4 月到美國找 Victoria 的旅行手冊：費城、紐約、華盛頓。版面與字體沿用葡萄牙・西班牙手冊。

- `index.html`：頁面外框、封面與影像來源
- `data.js`：全部行程資料（每日行程、航班、交通、門票、住宿、備忘），要改內容改這個檔
- `app.js`：把資料排成各個分頁
- `style.css`、`typography.css`：與葡萄牙・西班牙手冊相同的樣式與字體
- `usa.css`：這本手冊多出來的四段月曆配色

純靜態網站，沒有建置步驟。改完後把 `index.html` 裡 `?v=` 的版本字串也改掉，瀏覽器才會抓到新版。

照片連到 Wikimedia Commons，作者與授權列在頁尾「影像來源」。開放時間、票價和訂票規則查於 2026 年 11 月，出發前要再確認。
