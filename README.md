# Sonic 美國東岸旅行手冊 2027

Sonic 2027 年 4 月到美國找 Victoria 的旅行手冊：費城、紐約、華盛頓。版面與字體沿用葡萄牙・西班牙手冊。

- `index.html`：頁面外框、封面與影像來源
- `data.js`：中文行程資料（每日行程、航班、交通、門票、住宿、備忘）
- `data-en.js`：英文版的同一份資料。改行程時兩個檔都要改，結構和筆數要一致
- `app.js`：把資料排成各個分頁
- `style.css`、`typography.css`：與葡萄牙・西班牙手冊相同的樣式與字體
- `usa.css`：這本手冊自己的色系（天藍、雲白、計程車黃、磚紅）和四段月曆配色

純靜態網站，沒有建置步驟。改完後把 `index.html` 裡 `?v=` 的版本字串也改掉，瀏覽器才會抓到新版。

照片連到 Wikimedia Commons，作者與授權列在頁尾「影像來源」。開放時間、票價和訂票規則查於 2026 年 11 月，出發前要再確認。

## 語言與幣別

右上角可以切換繁體中文／English，以及台幣／美元。資料裡的金額一律用美元寫成 `{{30}}` 或 `{{24-36}}`，頁面會依選的幣別顯示。台幣是用參考匯率換算的約略數字：`app.js` 裡內建一筆（2026-10-11），連得上網時會向 frankfurter.dev 抓最新匯率。
